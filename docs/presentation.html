3 · Arquitetura

Por que módulo por camada, e não por feature

B · por camada escolhida

Três módulos: domínio, dados, app.

As quatro features são pastas dentro do app, já isoladas: nenhuma importa a outra.

C · por feature

Oito a doze módulos, um por feature mais os de base.

Cada um vira um alvo compilado para o iOS.

  • Um dev, quatro telas: o custo de C é real e o ganho dele (times em paralelo) não existe aqui
  • Promover para C depois é mover pastas, porque as fronteiras já estão respeitadas

5 · Implementação

Abrir a porta e confirmar que abriu

  • São duas coisas diferentes, e o app não junta as duas
  • Ele só diz que a porta abriu depois de ler o estado e ver que concorda
  • Se a fechadura não responde, o app diz que não sabe — não inventa
  • Nesta versão, comandos que mexem na porta vêm desligados
A porta é de uma conta compartilhada. Errar para o lado cauteloso é a escolha certa.

5 · Implementação

Como usei IA

  • Para escrever código. As decisões continuaram sendo minhas
  • Nada entra sem teste, e nada é mesclado sozinho
  • Toda decisão importante virou um documento curto com o motivo
  • Onde a IA errou, está anotado — e o que eu fiz para corrigir
Escrever rápido é fácil. O trabalho é revisar o que foi escrito.
